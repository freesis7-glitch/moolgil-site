한 줄 소개

물길은 바다낚시를 준비할 때 필요한 물때표, 바다날씨, 전자해도를 한 앱에 모은 무료 안드로이드 앱이며, 갤럭시 워치(Wear OS)에서도 물때를 볼 수 있습니다.

주요 기능

물때 · 조석

  • 전국 1,607개 지점의 물때표와 만조·간조 시각, 조위
  • 지역별 물때 셈법: 서해 7물때식, 남해·동해·제주 8물때식
  • 하루 조석 그래프와 주간 물때, 관심 지점 즐겨찾기

바다날씨

  • 기온, 하늘 상태, 시간별·일별 예보
  • 파고와 풍향·풍속, 수온과 수심별 수온 변화
  • 기상청 관측 부이의 실측값, 강수 레이더, 바다 위 바람 흐름을 보여 주는 바람 지도

전자해도

  • 국립해양조사원 해도 위에 수심 숫자와 등수심선
  • 인공어초(종류·설치연도·시설면적), 침선과 암초, 양식장·어장 정보, 조류 흐름
  • 내 위치 마커 저장, 항적 기록, 두 지점 거리 측정, GPX·USR 파일 불러오기와 내보내기

안전

  • 내 위치를 담은 링크를 가족·동료에게 보내는 SOS 구조 요청
  • 같이 나간 일행의 위치를 함께 보는 선단 공유
  • 간조 시각을 기준으로 단계별 경보를 주는 해루질 모드

갤럭시 워치

  • 현재 물높이, 다음 고조·저조, 바다날씨를 손목에서 확인
  • 타일, 정보 표시(컴플리케이션), 시계 화면 "물길 타이드 플로우"(Wear OS 6 이상)
  • 휴대폰 없이 단독으로 동작하고, 워치에서 저장한 위치는 휴대폰 앱 해도에 마커로 표시됩니다

홈 화면 위젯

  • 오늘 물때, 물때 그래프, 주간 물때, 날씨 등 위젯 14종

라이브 방송과 유튜브 계정 연결

  • 휴대폰 카메라 영상에 물때·시계·글자를 얹어 유튜브 라이브로 바로 방송합니다(시험 운영 중).
  • 방송 화면 속 글자는 시청자가 누를 수 없어서, 방송자가 원하면 '유튜브 계정 연결'로 한 번 허락해 둘 수 있습니다. 그러면 방송을 시작할 때 방송을 만들거나 찾아 고른 공개 상태로 맞추고, 영상이 들어오면 바로 실시간으로 넘기며, 설명란 맨 위와 채팅에 물길 링크(위치보기·앱 받기)를 넣습니다.
  • 이때 구글 권한 'YouTube 계정 관리(youtube.force-ssl)'를 요청하며, 받은 데이터는 내 라이브 방송을 만들거나 찾아 공개 상태·시작·종료를 맞추고 설명란·채팅에 링크를 넣는 데만 씁니다. 토큰과 유튜브 데이터는 물길 서버에 저장하지 않고, 앱의 '연결 끊기'나 구글 보안 설정에서 언제든 권한을 거둘 수 있습니다. 자세한 내용은 개인정보처리방침 8항에 있습니다.
  • In English: Moolgil's optional "Connect YouTube account" feature uses YouTube API Services (scope youtube.force-ssl) only to create or find the user's own live broadcast, set its privacy status, start and end it, and add a Moolgil link to its description and live chat. Tokens and YouTube data are not stored on our servers. See our Privacy Policy.
