라이브 방송과 유튜브 계정 연결

물길은 휴대폰 카메라 영상에 물때·시계·글자를 얹어 유튜브 라이브로 바로 방송하는 기능을 시험 운영하고 있습니다. 방송자가 원하면 '유튜브 계정 연결'로 한 번 허락해 둘 수 있고, 그러면 방송을 시작할 때 방송을 만들거나 찾아 고른 공개 상태로 맞추고, 영상이 들어오면 바로 실시간으로 넘기며, 설명란과 채팅에 물길 링크(위치보기·앱 받기)를 넣습니다.

이때 구글 권한 'YouTube 계정 관리(youtube.force-ssl)'를 요청합니다. 받은 데이터는 내 라이브 방송을 만들거나 찾아 공개 상태·시작·종료를 맞추고 설명란·채팅에 링크를 넣는 데만 쓰며, 토큰과 유튜브 데이터는 물길 서버에 저장하지 않습니다. 앱의 '연결 끊기'나 구글 보안 설정에서 언제든 권한을 거둘 수 있습니다. 자세한 내용은 개인정보처리방침에 있습니다.

Moolgil's optional "Connect YouTube account" feature uses YouTube API Services (scope youtube.force-ssl) only to create or find the user's own live broadcast, set its privacy status, start and end it, and add a Moolgil link to its description and live chat. Tokens and YouTube data are not stored on our servers. See our Privacy Policy.
