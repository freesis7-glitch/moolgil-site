개인정보처리방침

2026년 11월 9일 기준

한 줄 소개

물길은 이용자가 켠 기능에 필요한 정보만 쓰고, 개인정보를 판매하거나 광고에 쓰지 않습니다. 유튜브 계정 연결로 받은 구글 사용자 데이터는 내 라이브 방송을 만들거나 찾아 공개 상태·시작·종료를 맞추고 설명란·채팅에 물길 링크를 넣는 데만 쓰며 서버에 저장하지 않습니다.

시행일: 2026년 11월 9일 · 앱 이름: 물길 (com.mulnale.app) · 이전 판 시행일: 2026년 7월 2일

물길(이하 "앱")은 이용자의 개인정보를 소중히 여기며, 「개인정보 보호법」과 관련 법령을 지킵니다. 이 방침은 물길 안드로이드 앱, 갤럭시 워치 앱, 이 웹사이트(moolgil.com)에 적용됩니다.

1. 수집하는 개인정보 항목

로그인할 때

  • 이메일 주소, 소셜 로그인 식별자(카카오·구글)
  • 이름, 프로필 사진(소셜 서비스가 제공하는 경우)

앱을 쓸 때

  • 위치 정보(GPS): 현재 위치 기준 물때·날씨 조회
  • 이동 항적(궤적), 낚시 포인트·메모 마커의 위치 좌표
  • 조과(낚시 기록)의 위치·사진, 즐겨찾기 지점, 앱 설정

로그인한 경우 위 정보는 기기 사이 동기화를 위해 서버(Supabase)에 저장됩니다.

라이브 방송 기능을 쓸 때

  • 카메라 영상·마이크 소리: 앱 안에서 이용자가 정한 방송 플랫폼(유튜브 등)으로 바로 보냅니다. 물길 서버로 보내거나 저장하지 않습니다.
  • 방송 플랫폼 스트림 키: 이용자 기기에만 저장하고 물길 서버로 보내지 않습니다.
  • 위치 공개를 켠 경우: 방송 중 현재 위치(좌표·진행 방향·속도·정확도)와 위치 설명(예: 가까운 항 기준 방향·거리)·물때·수온·날씨를 10초마다 서버로 보냅니다.

유튜브 계정을 연결할 때 — 아래 8항에 따로 적습니다.

2. 개인정보 수집 및 이용 목적

  • 소셜 로그인과 서비스 이용
  • 현재 위치 기준 물때·날씨·해도 정보 제공
  • 즐겨찾기·항적·조과·메모 저장과 기기 사이 동기화
  • 선단(그룹) 기능을 쓸 때 참여자 사이 실시간 위치 공유
  • 라이브 방송 화면의 물때·위치 정보 표시, 방송자가 고른 경우 시청자에게 방송 중 위치 공개
  • 유튜브 계정을 연결한 경우 방송 설명란·채팅에 물길 링크 넣기
  • 앱 서비스 품질 개선

3. 개인정보 보유 및 이용 기간

앱 안 '계정 삭제' 또는 삭제 요청 때 서버에 저장된 개인정보(이메일·항적·조과·메모·즐겨찾기 등)를 지체 없이 파기합니다. 다만 관련 법령에 따라 서비스 이용 기록은 3개월간 보관할 수 있습니다(통신비밀보호법).

라이브 위치 공개 정보는 마지막 전송 뒤 최대 90초까지만 보관하고, 방송을 끝내면 바로 지웁니다. 서버에는 이동 궤적을 남기지 않습니다.

4. 개인정보 제3자 제공

이용자의 개인정보를 제3자에게 판매하거나 제공하지 않습니다. 다만 아래의 경우 위치 등 정보가 전달됩니다.

  • 선단(그룹) 기능: 이용자가 참여를 고른 경우 실시간 위치가 같은 선단 참여자에게 공유됩니다.
  • 현재 위치 기준 날씨·해양 정보 조회를 위해 위치 좌표가 외부 데이터 제공처로 전송될 수 있습니다.
  • 라이브 방송: 영상·소리는 이용자가 고른 방송 플랫폼으로 바로 전송되며 그 플랫폼의 정책이 적용됩니다.
  • 라이브 위치 공개: 이용자가 켠 경우 공개 링크를 가진 누구나 방송 중 위치를 볼 수 있습니다.

5. 개인정보 처리 위탁

  • Supabase Inc. (데이터베이스·인증 호스팅, 미국)
  • Fly.io (백엔드 서버 호스팅, 일본)
  • Google Firebase (푸시 알림, 미국)
  • Kakao Corp. (소셜 로그인, 대한민국)

6. 위치 정보 이용

위치 정보는 물때·날씨·해도 조회에 씁니다. 로그인 뒤 항적·포인트·조과를 저장하면 그 위치 좌표가 서버에 저장되고, 선단 기능을 쓰면 실시간 위치가 참여자에게 공유됩니다. 라이브 방송에서 위치 공개를 켜면 방송 중 위치가 공개 링크로 표시되며, 위치 공개는 라이브 설정에서 언제든 끌 수 있습니다. 위치·카메라·마이크 권한은 언제든 기기 설정에서 거둘 수 있습니다.

7. 이용자의 권리

  • 개인정보 열람·수정·삭제 요청
  • 개인정보 처리 정지 요청
  • 계정 삭제(앱 메뉴 → 프로필 → '계정 삭제')

그 밖의 요청은 아래 이메일로 보내 주시면 지체 없이 처리합니다.

8. 유튜브 계정 연결과 구글 사용자 데이터 (YouTube API 서비스)

물길의 라이브 방송 기능에는 '유튜브 계정 연결'이 있습니다. 이 기능은 YouTube API 서비스를 씁니다. 연결은 이용자가 직접 켤 때만 이루어지며, 켜지 않아도 방송은 할 수 있습니다.

  • 이 기능을 쓰면 YouTube 서비스 약관을 따르는 데 동의하게 됩니다.
  • 구글이 이 데이터를 어떻게 다루는지는 Google 개인정보처리방침에서 볼 수 있습니다.

요청하는 권한: https://www.googleapis.com/auth/youtube.force-ssl (유튜브 계정 관리). 연결할 때 구글 허락 화면에 이 권한이 표시됩니다.

접근하는 데이터와 쓰는 곳

  • 연결한 계정의 유튜브 채널 이름: 연결이 됐는지 라이브 설정 화면에 보여 주는 데만 씁니다.
  • 내 채널의 라이브 스트림 정보(스트림 ID·스트림 키 이름·상태): 앱에 넣어 둔 스트림 키와 같은 스트림을 찾고, 그 스트림에 영상이 들어오고 있는지 확인하는 데 씁니다. 비교는 휴대폰 안에서만 하며 스트림 키를 물길 서버로 보내지 않습니다.
  • 그 스트림에 묶인 내 라이브 방송의 ID·제목·설명·예약 시각·공개 상태·진행 상태·라이브 채팅 ID(바로 고칠 수 없을 때는 그 영상의 제목·설명·태그·분류·언어·공개 설정): 방송을 찾고, 고칠 때 기존 값을 그대로 두는 데 씁니다.
  • 방송 만들기: 그 스트림에 묶인 방송이 없으면 내 채널에 새 라이브 방송을 하나 만들어 스트림에 묶습니다. 제목은 '채널 이름 실시간 방송 날짜 시각', 공개 상태는 고른 값, 자동 시작·자동 종료와 처음부터 녹화(다시보기)가 켜집니다. 아동용 여부는 물길이 정하지 않으며 채널의 시청자층 설정을 따릅니다.
  • 공개 상태 맞추기: 라이브 설정에서 고른 값(공개·일부 공개·비공개, 기본값 공개)으로 방송의 공개 상태를 바꿉니다. '유튜브 설정대로'를 고르면 이미 있는 방송은 바꾸지 않고, 새로 만드는 방송은 공개로 만듭니다.
  • 방송 시작·종료: '송출되면 바로 실시간으로'를 켜 두면, 영상이 유튜브에 들어오기 시작할 때 방송을 실시간으로 넘기고(유튜브 스튜디오의 '실시간 스트리밍 시작'과 같은 동작), 물길이 실시간으로 넘긴 방송은 이용자가 앱에서 방송을 끝낼 때 함께 종료합니다.
  • 방송 설명란 수정: '물길 링크 넣기'를 켜 두면 설명란 맨 위에 "물길 앱으로 방송 중" 한 줄과 위치보기·앱 받기 링크를 넣습니다. 기존 설명은 그대로 아래에 둡니다.
  • 라이브 채팅 글쓰기: 같은 링크를 채팅에 한 번 올립니다.

위 기능은 라이브 설정에서 각각 끌 수 있습니다. 물길은 위 목적 밖으로 유튜브 데이터를 읽거나 바꾸지 않습니다. 위의 라이브 방송 만들기 말고는 영상 올리기·삭제, 댓글 관리, 구독, 채널 설정 변경, 시청 기록 조회는 하지 않습니다.

저장·공유하지 않음

  • 구글이 발급하는 접근 토큰은 기기의 구글 플레이 서비스가 관리하며, 물길 앱 저장소나 물길 서버에 저장하지 않습니다.
  • 유튜브에서 받은 데이터는 그 자리에서 위 작업에만 쓰고 서버에 남기지 않습니다. 기기 안에는 연결 여부를 보여 주는 채널 이름만 저장되고 연결을 끊으면 지워집니다. 방송을 끝낼 때 종료할 방송을 알기 위한 방송 ID는 방송하는 동안 앱 메모리에만 두었다가 버립니다.
  • 유튜브 데이터를 제3자에게 팔거나 넘기지 않고, 광고에 쓰지 않으며, 인공지능 학습에 쓰지 않습니다. 사람이 읽지도 않습니다(이용자가 직접 요청하거나 보안·법령상 필요한 경우 제외).
  • 유튜브 API와 주고받는 모든 통신은 HTTPS로 암호화됩니다.

연결 끊기(권한 철회)

  • 앱: 라이브 설정 → '유튜브 설명란·채팅 링크' → 연결 끊기. 누르면 구글에 준 권한을 바로 거둡니다.
  • 구글 보안 설정: https://security.google.com/settings/security/permissions 에서 '물길'을 찾아 접근 권한을 삭제할 수 있습니다.
  • 물길은 유튜브 데이터를 저장하지 않으므로 지울 데이터가 남지 않습니다. 저장된 정보 삭제를 원하시면 아래 이메일로 요청해 주세요. 7일 안에 처리합니다. 물길 쪽 정보를 지워도 유튜브에 저장된 내 방송·채팅 내용에는 영향이 없습니다.

제한적 사용(Limited Use): 물길이 구글 API에서 받은 정보를 쓰고 다른 앱으로 옮기는 일은 Google API 서비스 사용자 데이터 정책의 제한적 사용 요구사항을 포함해 그 정책을 따릅니다.

Privacy Policy — Google user data and YouTube API Services (English summary)

Effective November 9, 2026. App: 물길 (Moolgil), Android package com.mulnale.app. Developer contact: freesis7@gmail.com.

Moolgil is a free Android sea-fishing app (tide tables, marine weather, nautical charts). Its live-streaming feature offers an optional "Connect YouTube account" function. This function uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. See also the Google Privacy Policy.

Scope requested: https://www.googleapis.com/auth/youtube.force-ssl, requested only when the user taps "Connect YouTube account".

What we access and why

  • The connected account's YouTube channel title, shown in the app's live settings to confirm the connection.
  • The user's own live streams (stream ID, stream name/key, status). These are used to find the stream that matches the stream key the user entered in the app, and to check that video is arriving. The comparison happens on the device, and the stream key is never sent to our servers.
  • The user's own live broadcast bound to that stream (ID, title, description, scheduled times, privacy status, life cycle status, live chat ID; if the broadcast cannot be updated directly, the video's title, description, tags, category, language and privacy settings). These are used to find the broadcast and to keep existing values unchanged when it is updated.
  • Creating a broadcast: if no broadcast is bound to that stream, the app creates one live broadcast on the user's channel and binds it to the stream. Title: "<channel> 실시간 방송 <date> <time>". It uses the chosen privacy status, with auto-start, auto-stop and recording from start (replay) on. Moolgil does not set the "made for kids" status; the channel's audience setting applies.
  • Privacy status: the broadcast's privacy status is set to the value chosen in live settings (Public, Unlisted or Private; default Public). With "Follow YouTube settings", an existing broadcast is left unchanged and a newly created broadcast is made public.
  • Start and end: with "Go live as soon as streaming starts" on, the broadcast is transitioned to live when video starts arriving (the same action as "Go live" in YouTube Studio). A broadcast that Moolgil transitioned to live is completed when the user ends the stream in the app.
  • Description: with "Add Moolgil link" on, one line "물길 앱으로 방송 중" (streaming with the Moolgil app) and links to the viewer location page and the Play Store are added at the top of the description. The existing description is kept below.
  • One live chat message containing the same link.

Each of these functions can be turned off in live settings. Apart from creating the live broadcast described above, Moolgil does not upload or delete videos, manage comments, subscriptions or channel settings, or read watch history.

Storage and sharing: Access tokens are managed by Google Play services on the device and are never stored by the app or sent to our servers. YouTube API data is used immediately for the actions above and is not stored on our servers. On the device, only the channel title is stored (to show the connection status), and it is removed on disconnect. The broadcast ID needed to end the broadcast is kept only in app memory while streaming. We do not sell or transfer Google user data, use it for advertising, or use it to train AI/ML models. Humans do not read it unless you ask us to, or unless security or legal requirements apply. All requests use HTTPS.

Revoking access: In the app, go to Live settings, then Disconnect. This revokes the token immediately. You can also remove access at any time via the Google security settings page: https://security.google.com/settings/security/permissions. To request deletion of any data related to you, email freesis7@gmail.com. We will respond within 7 days. Deleting data on our side does not affect data stored by YouTube.

Limited Use: Moolgil's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Cookies: The app does not use cookies. This website uses Google Analytics cookies for anonymous visit statistics.
